# Hammunition Bunker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A container service that keeps a verified copy of Hammunition's offline data on a NAS, fresh on a per-unit schedule, and serves it read-only on the LAN at `<mirror>/<unit>/<name>`.

**Architecture:** `bunker` asks an installed engine what to keep (`hammunition artifacts --json`, a subprocess), downloads through the engine's own verifier (`hammunition.fetch.Fetcher`, imported), lays each artifact out on one volume with a sha256 sidecar and one `.previous`, and records the volume in `index.json` (version 1) and `status.html`. A stdlib HTTP server serves only what the index names, with byte ranges. A scheduler runs the pass daily and serves in the same process.

**Tech Stack:** Python 3.11+ stdlib (`tomllib`, `http.server`, `fcntl`, `concurrent.futures`), the Hammunition engine as the one dependency, pytest, mypy --strict, ruff; Debian 13 slim image; GYST shared CI.

**Spec:** `docs/superpowers/specs/2026-09-29-bunker-design.md` (its "as built" notes on the engine side are binding).

## Global Constraints

- Package `bunker` under `src/bunker/`; console script `bunker`; licence GPL-3.0-or-later; copyright Renegade Penguin LLC; SPDX header on every source file.
- Engine dependency pinned by git tag: `hammunition @ git+https://github.com/ChiefGyk3D/Hammunition@v0.16.0` (the release the `artifacts-mirror` branch ships as; 0.15.0 is the current tag and lacks D-070). Development uses `pip install -e /home/chiefgyk3d/src/Hammunition-mirror --config-settings editable_mode=compat` (compat so mypy can follow it).
- Commands: `bunker run|status|verify|serve|schedule|doctor`, each with `--config PATH` (default `/etc/bunker/bunker.toml`, then `./bunker.toml`); `--json` where a document exists, D-059 envelope shape.
- Exit codes: 0 clean, 1 failures, 2 refused (config, index, arguments), 125 a run is in progress.
- Downloads: 2 at a time by default, never more than 4. Cadences: `never | daily | weekly | monthly`.
- Tests: no socket except loopback; a fake `hammunition` on PATH; a loopback publisher; a temp volume. Never the real network.
- Example config names public example regions only: Vermont, New Hampshire, Delaware. Placeholders only for any station value (none is needed).
- Nothing downloaded is executed, unpacked or parsed beyond hashing.
- Machine rules while building: `nice -n 19 ionice -c 3`; no Docker/Podman build here (the Dockerfile is written, not built); no sudo; no push.

## Review Focus

1. **An artifact name or unit from the engine that could leave the volume** (`..`, a leading `.`, an empty segment, a unit with `/`, a unit named like a top-level file) — expected: that artifact fails by name, nothing is written outside `<root>`, the rest of the run proceeds. Test in Task 5 (`test_unsafe_names_are_refused`) and Task 6 (`test_unsafe_artifact_fails_alone`).
2. **A download that dies half-way or is the wrong size / wrong bytes** — expected: the serving copy is untouched, nothing unverified is left in `.incoming`, the failure has the verifier's reason. Task 6 (`test_wrong_hash_keeps_previous_serving`, `test_incoming_left_clean`).
3. **The engine answering with an `error` document, a non-zero exit, garbage, or a schema major we do not know** — expected: the run fails loudly with the engine's stderr/message, the index keeps its artifacts, `.runs.jsonl` records the failure. Task 4 and Task 6 (`test_engine_failure_is_recorded`).
4. **An `index.json` that is corrupt, newer than this Bunker, or absent** — expected: corrupt and newer refuse with exit 2 naming the file and the fix; absent is an empty index. Task 5 (`test_index_corrupt_refuses`, `test_index_newer_refuses`).
5. **A request for something that is on disk but not served** (`.previous`, `.incoming/...`, `.lock`, `.runs.jsonl`, `%2e%2e` traversal, a directory) — expected: 404, identical to a name that does not exist. Task 8 (`test_hidden_paths_are_404`).

### Task 6: The run

**Files:** Create `src/bunker/run.py`, publisher fixture in `tests/conftest.py`, `tests/test_run.py`.

**Interfaces — Consumes:** Tasks 2, 4, 5. **Produces:**
```python
PERIOD = {"daily": 1d, "weekly": 7d, "monthly": 30d}; SLACK = 1h
def due(cadence: str, last: datetime | None, now: datetime) -> bool          # never -> False; None -> True
def verify_due(cadence, size, last, now) -> bool                              # auto: every run < 1 GiB, monthly above
@dataclass class Outcome: unit, name, action ("fetched"|"verified"|"unchanged"|"stale"|"failed"|"corrupted"), status, reason
@dataclass class RunReport: started, finished, engine_version, outcomes, deferred, dropped, error; counts(); exit_code
def run(cfg, *, all_=False, units=(), now=utcnow, transport=None) -> RunReport   # raises Locked

```
Per artifact: missing → fetch; sidecar/record matches expected → `unchanged`, re-hashed when verify is due (`verified`, or `corrupted` → file removed and fetched now); differs and the unit's cadence is due (or `--all`, or named by `--unit`) → fetch; differs and not due → `stale`. Fetch: `Fetcher(cache_dir=<root>/.incoming/<unit>)`; `sha256`/`sha256-publisher` → `fetch(RemoteArtifact(url, sha256=digest), max_bytes=size+1MiB)`; `md5-publisher`/`etag-md5` → `fetch_md5(url, digest, expected_size=size)`; a listed artifact with no digest, or md5 with no size, fails by name (nothing unverified is kept); result size ≠ listed size fails. Two workers (`ThreadPoolExecutor(max_workers=cfg.storage.downloads)`), installs and index writes under one `threading.Lock`. Index entries of units this run did not cover are kept; entries of covered units the engine no longer lists are dropped from the index (files left, named in the report as `dropped`). Engine failure: index artifacts kept, `last_run.error` set. Every run: `index.json`, `status.html`, one line in `.runs.jsonl`, a plain summary on stdout.

### Task 8: The server

**Files:** Create `src/bunker/server.py`, `tests/test_server.py`.

**Interfaces — Produces:** `make_server(root: Path, bind: str, port: int) -> ThreadingHTTPServer`; `Routes.load(root)` rebuilt when `index.json`'s mtime changes: `/` and `/status.html` → status page, `/index.json`, `/<unit>/<name>` → the entry's file, `/<path>` and `/<path>.sha256` for each entry's current path.
